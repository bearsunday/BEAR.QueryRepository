## Additional Notes

This section was added later (2025-11-11) to provide detailed migration guides and examples.

### Added

- Added surrogate key support to Donut view (#118)
  - Donut cache now includes surrogate keys for proper cache invalidation
  - Enables CDN-level purging of donut-cached pages
  - Surrogate keys from embedded resources are propagated to the donut cache

  **Example**:
  ```php
  // When a page uses donut caching with embedded resources
  class Page extends ResourceObject
  {
      #[Embed(rel: 'user', src: 'app://self/user?id={id}')]
      public function onGet(int $id): static
      {
          // The user resource's surrogate keys will be
          // automatically added to the donut cache tags
          return $this;
      }
  }

  // Purging the user resource will now correctly invalidate
  // all donut-cached pages that embed it
  ```

### Fixed

- Fixed caching of error responses (#115)
  - Resources returning error codes (4xx, 5xx) are no longer cached
  - Prevents serving stale error responses from cache
  - Only successful responses (2xx, 3xx) are cached

  **Impact**:
  ```php
  class User extends ResourceObject
  {
      public function onGet(int $id): static
      {
          if (!$this->userExists($id)) {
              $this->code = 404; // This will NOT be cached
              return $this;
          }

          $this->body = $this->userData($id);
          $this->code = 200; // This WILL be cached
          return $this;
      }
  }
  ```

  **Before**: Error responses were cached, potentially serving 404s from cache even when the resource became available

  **After**: Only successful responses are cached, ensuring error conditions are always checked in real-time

- Improved error handling for serialization failures
  - Added proper exception catching for resource serialization errors
  - Prevents cache corruption when serialization fails
  - Improves stability when dealing with non-serializable resources
