## Additional Notes

This section was added later (2025-11-11) to provide detailed migration guides and examples.

### Changed

- **⚠️ Breaking Change** Dropped PHP 7.4 support, now requires PHP 8.0+ (#123)
  - **Before**: Supports PHP 7.4 and above
  - **After**: Requires PHP 8.0 or higher
  - **Rationale**: PHP 7.4 reached end-of-life on November 28, 2022. Dropping support allows optimization for PHP 8 features
  - **Migration**:
    ```bash
    # Update your composer.json
    # Before
    "require": {
        "php": "^7.4 || ^8.0"
    }

    # After
    "require": {
        "php": "^8.0"
    }
    ```
  - If your project still uses PHP 7.4, you must upgrade to PHP 8.0 or later before updating to this version
  - Consider using version 1.8.x if PHP 7.4 support is required

### Fixed

- Fixed manually set surrogate keys being overwritten (#122, fixes #121)
  - Previously, surrogate keys manually set on ResourceObject were ignored and replaced with automatically generated keys
  - Now preserves custom surrogate keys set by the application
  - Enables fine-grained cache invalidation control

  **Example**:
  ```php
  // Your custom surrogate keys are now preserved
  class User extends ResourceObject
  {
      public function onGet(int $id): static
      {
          // Manually set surrogate key for custom cache invalidation
          $this->headers['Surrogate-Key'] = "user-{$id} user-list";
          $this->body = ['id' => $id, 'name' => 'Example'];

          return $this;
      }
  }

  // These keys will be preserved and available for CDN purging
  ```

- Fixed Surrogate-Key HTTP header not being output for Page resources (#119)
  - Surrogate-Key headers set on Page resources are now properly preserved and output
  - Previously, keys were stored in ResourceStorage as tags but not sent as HTTP headers
  - Ensures CDN cache invalidation works correctly for page-level resources

  **Impact**: Page-level cache invalidation with CDNs (Fastly, Akamai) now works as expected
