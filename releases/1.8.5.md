### Fixed

- Fixed surrogate-key refresh issue (#114)
  - Corrects cache invalidation when updating resources with surrogate keys
  - Ensures dependent caches are properly invalidated
  - Improves reliability of cache refresh mechanism

  **Impact**: Cache invalidation now works correctly when using `#[Refresh]` annotation with surrogate keys

  ```php
  class User extends ResourceObject
  {
      #[Cacheable]
      public function onGet(int $id): static
      {
          $this->headers['Surrogate-Key'] = "user-{$id}";
          // Resource data...
          return $this;
      }
  }

  class UpdateUser extends ResourceObject
  {
      #[Refresh(uri: 'app://self/user?id={id}')]
      public function onPut(int $id, array $data): static
      {
          // Update logic...
          // Surrogate keys are now correctly refreshed
          return $this;
      }
  }
  ```
