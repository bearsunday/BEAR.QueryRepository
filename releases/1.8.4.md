## Additional Notes

This section was added later (2025-11-11) to provide detailed migration guides and examples.

### Added

- Added support for doctrine/cache v1.12+ (#110)
  - Now supports both doctrine/cache v1.12+ and v2.0
  - Provides backward compatibility with older projects using doctrine/cache v1
  - Enables gradual migration path from doctrine/cache v1 to v2

  **Compatibility**:
  ```json
  // composer.json now accepts both versions
  "require": {
      "doctrine/cache": "^1.12 || ^2.0"
  }
  ```

  **Migration**: No action required. The package works with both versions seamlessly.

  ```php
  // Works with both doctrine/cache v1 and v2
  use Doctrine\Common\Cache\Cache;

  // Your existing code continues to work regardless of
  // which version of doctrine/cache is installed
  ```

  **Note**: This change is particularly useful for legacy projects that cannot immediately upgrade to doctrine/cache v2, allowing them to still use the latest version of BEAR.QueryRepository.
