### Fixed

- Fixed refresh command returning wrong object when ResourceObject has error code (#108)
  - Previously, refresh commands could return incorrect objects when the refreshed resource had an error status
  - Now properly handles error responses during cache refresh operations
  - DonutCommand also skips refresh when the resource request results in an error

  **Impact**:
  ```php
  class User extends ResourceObject
  {
      #[Cacheable]
      public function onGet(int $id): static
      {
          if (!$this->userExists($id)) {
              $this->code = 404;
              return $this;
          }
          // ...
      }
  }

  class UpdateRelated extends ResourceObject
  {
      #[Refresh(uri: 'app://self/user?id={id}')]
      public function onPut(int $id): static
      {
          // If the user resource returns 404 during refresh,
          // it now correctly handles the error case
          return $this;
      }
  }
  ```

  **Before**: Refresh command could return unexpected objects when encountering error responses

  **After**: Refresh command properly handles error responses and maintains correct object state
